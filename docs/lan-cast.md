# PiliPlus 局域网推送

两台设备安装包含此功能的 PiliPlus，连接同一 Wi-Fi 或有线局域网。

1. 接收端：打开 **设置 → 播放设置 → 局域网推送 → 在此设备接收播放**，保持页面打开。
2. 发送端：打开在线视频或直播，点击播放器顶部的 **局域网推送** 按钮（电视图标）。
3. 选择接收设备，输入接收端显示的六位连接码。搜索不到时可以手动输入接收端显示的 `IP:端口`。
4. 推送成功后，本机暂停，发送端显示遥控器。支持播放/暂停、拖动进度、前后 10 秒、音量/静音和倍速；直播只显示可用操作。
5. 返回其他页面不会停止接收端播放。通过播放器按钮或设置里的“局域网推送”重新打开遥控器；“推送当前视频”可以切换到新视频。
6. 点击“结束推送并停止播放”，或在接收端点击“断开并停止播放”。关闭接收页面也会停止播放并撤销连接。

自动发现使用 Bonjour/mDNS (`_piliplus._tcp`)。Android 17 及以上、iOS/macOS 请允许本地网络访问，桌面系统请允许 PiliPlus 的入站连接。Linux 自动发现需要运行 Avahi；自动发现不可用时可使用手动地址。当前使用局域网 IPv4 连接，不跨越路由器的访客网络隔离。

接收端直接读取视频地址，不传输账号 Cookie 或登录凭据，支持分离的视频/音频流。当前不推送本地缓存文件、弹幕、字幕和播放列表。视频链接过期时，在发送端重新加载视频再推送。移动接收端需保持应用和接收页面在前台；发送端退出应用后需要在接收端断开，才能重新配对。

## 开发验证

- `flutter analyze --no-fatal-infos`
- `flutter test test/services/lan_cast/`
- 按项目构建脚本给 Flutter、material_ui、cupertino_ui 应用补丁后构建目标平台。

通信测试使用真实回环 HTTP 服务与模拟播放器，覆盖配对、分离音轨、进度/音量/倍速、断开、令牌撤销、错误请求及并发加载。设备发现和真实解码仍需在两台设备上联调。
